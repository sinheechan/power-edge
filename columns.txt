power-edge ML 컬럼 설명
==================================================
목표: 15분 평균 전력을 구간이 끝나기 전에 미리 맞힌다
방식: 기존 계산식(proj_base) + 모델이 배운 보정값(residual)


[원본] 공장 CSV, 1초 간격
--------------------------------------------------
timestamp       측정 시각
active_power    유효전력 (W → kW, 공장 규모 1400kW로 배율)
voltage         전압 (시뮬레이터 전용, 학습 미사용)


[파생] 모델 입력 15개, 10초 평균 기준
--------------------------------------------------
# 진행도
  elapsed_ratio   구간 진행률 (0~1)
  used_kwh        이번 구간 누적 사용량

# 현재·예측
  kw_now          지금 전력
  proj_base       기존 계산식 예측 (지금 전력 유지 가정)
  proj_trend      추세 반영 예측 (최근 5분 기울기 유지 가정)

# 최근 흐름
  mean_1m / 5m / 10m   최근 1·5·10분 평균
  std_5m               최근 5분 출렁임
  slope_5m             최근 5분 기울기 (+ 상승 / - 하강)
  max_10m / min_10m    최근 10분 최대·최소

# 시간
  hour_sin / hour_cos  하루 중 시각
  dow                  요일

# 딥러닝 전용
  X_seq           최근 10분 전력 60칸 (GRU, 1D-CNN 입력)


[정답]
--------------------------------------------------
actual_kw       실제 15분 평균 전력
residual        actual_kw - proj_base  ← 모델이 배우는 값


[평가 지표]
--------------------------------------------------
test_mae        평균 오차 (kW, 작을수록 좋음)
test_mae_early  구간 초반 8분 오차
missed_peaks    놓친 피크 수
false_alarms    헛경보 수
early_min       피크를 몇 분 일찍 알아챘나
